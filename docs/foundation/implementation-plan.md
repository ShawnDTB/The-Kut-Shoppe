# Phased implementation plan

## Phase 1 — Audit and foundation

- Current-site inventory
- Proposed sitemap and initial route map
- Verification register
- React, TypeScript, Vite, prerendering, Cloudflare, and CI scaffold
- Configuration-driven business content

## Phase 2 — Brand and responsive system

- Final typography and logo treatment
- Accessible mobile navigation
- Reusable sections, cards, buttons, breadcrumbs, and notices
- Authentic shop photography direction

## Phase 3 — Core route implementation

- Homepage
- Services and booking router
- Team and professional profiles
- Gallery, about, reviews, visit, products, and contact

## Phase 4 — Content and assets

- WordPress content export
- Gallery inventory, categorization, and image optimization
- Approved review selection
- Team biographies, social links, and direct booking URLs

## Phase 5 — SEO, accessibility, security, and performance

- Sitemap and structured data
- WCAG 2.2 AA review
- Core Web Vitals optimization
- Contact-form validation and rate limiting
- Privacy-conscious analytics

## Phase 6 — Staging and launch

- Client verification
- Cross-device and direct-route testing
- Redirect validation
- Cloudflare staging review
- Domain migration and post-launch monitoring

The WordPress website remains production until phase-six approval.
